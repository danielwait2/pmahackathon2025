# Phase 3: Dashboard & Project Creation

> **Time Estimate:** 2.5 hours
> **Priority:** MUST
> **Prerequisites:** Phase 1 complete (auth + database working)
> **Rubric:** Design & UX (intuitive flows), Creativity (quick setup for expectations)

## Goal

Build the main dashboard where users see their projects, create new projects via a guided wizard, and join projects via invite code.

---

## Steps

### 3.1 Dashboard Page

**`app/(dashboard)/dashboard/page.tsx`** — Server Component

This page:
1. Fetches the current user's session (server-side)
2. Queries projects the user is a member of (via `project_members`)
3. For each project, fetches member count and task completion stats
4. Passes data to client components

**Data query pattern:**
```sql
-- Fetch user's projects with stats
SELECT
  p.*,
  (SELECT COUNT(*) FROM project_members pm WHERE pm.project_id = p.id) as member_count,
  (SELECT COUNT(*) FROM tasks t WHERE t.project_id = p.id) as total_tasks,
  (SELECT COUNT(*) FROM tasks t WHERE t.project_id = p.id AND t.status = 'done') as completed_tasks
FROM projects p
INNER JOIN project_members pm ON pm.project_id = p.id
WHERE pm.user_id = :current_user_id
ORDER BY p.created_at DESC
```

**Layout:**
- Header bar: User avatar (from profile), user name, logout button
- Page title: "Your Projects"
- Action buttons: "Create Project" + "Join Project"
- Project grid below (or empty state)

### 3.2 Project Card Component

**`components/dashboard/ProjectCard.tsx`** — Client Component

Each card displays:
- **Project name** (bold, truncated if long)
- **Deadline badge:**
  - Green if > 7 days away
  - Yellow/amber if 3-7 days away
  - Red if < 3 days or overdue
  - Show "X days left" or "Overdue"
- **Member count:** Avatar stack (up to 3) + "+X more" if > 3 members
- **Progress bar:** Tasks completed / total tasks, with percentage
- **Click handler:** Navigate to `/project/[id]`

Design:
- shadcn `Card` component
- Hover: subtle shadow lift
- Compact but informative

### 3.3 Empty State

**`components/dashboard/EmptyState.tsx`**

When user has no projects:
- Illustration area (can use a Lucide icon like `FolderOpen` at large size)
- "No projects yet"
- "Create your first project or join one with an invite code."
- Two buttons: "Create Project" and "Join Project"

### 3.4 Project List

**`components/dashboard/ProjectList.tsx`** — Client Component

- Receives projects array as prop
- If empty → render `<EmptyState />`
- Otherwise → render grid of `<ProjectCard />` components
- Grid: 1 column on mobile, 2 on tablet, 3 on desktop

### 3.5 Create Project Wizard

**`components/dashboard/CreateProjectWizard.tsx`** — Client Component

A multi-step modal/dialog wizard with 3 steps.

**Step 1: Basic Info**
- Project name (required, text input, max 100 chars)
- Description (optional, textarea, max 500 chars)
- Deadline (required, date picker — use shadcn `Calendar` + `Popover`)
- Validation: name required, deadline must be in the future
- "Next" button (disabled until valid)

**Step 2: Quick Setup (Team Expectations)**
- Response time expectation (select dropdown):
  - "Within 1 hour"
  - "Within 4 hours"
  - "Within 24 hours"
  - "Within 48 hours"
- Meeting frequency (select dropdown):
  - "Daily"
  - "Twice a week"
  - "Weekly"
  - "As needed"
- Preferred communication (select dropdown + optional custom input):
  - "iMessage"
  - "Discord"
  - "Slack"
  - "GroupMe"
  - "Other" → shows text input
- "Skip" button (skips to step 3 with defaults) and "Next" button

**Step 3: Invite Team**
- Show the generated invite code prominently (large, monospace font)
- Full invite URL: `{window.location.origin}/join/{code}`
- "Copy Link" button → copies URL to clipboard → toast "Link copied!"
- "Copy Code" button → copies just the 6-char code
- "Done — Go to Project" button

**On wizard completion (between step 1→2):**
1. Create project row in `projects` table
2. Create `project_members` row with role `'owner'`
3. If step 2 was filled (not skipped), create `team_agreements` row
4. The invite code is auto-generated by the database trigger

**Technical notes:**
- Use `useState` for wizard step tracking
- Use `useState` or react-hook-form for form state
- The dialog should use shadcn `Dialog` component
- Progress indicator: 3 dots or numbered steps at top of dialog

### 3.6 Join Project Modal

**`components/dashboard/JoinProjectModal.tsx`** — Client Component

Simple modal with:
- Title: "Join a Project"
- Text input for invite code (6 characters, uppercase, alphanumeric)
- Auto-uppercase as user types
- "Join" button
- On submit:
  1. Query `projects` where `invite_code = input`
  2. If not found → error: "Invalid invite code. Check with your team."
  3. If found → check if already a member
  4. If already member → toast: "You're already in this project" → navigate to project
  5. If not member → navigate to `/join/[code]` for confirmation

### 3.7 Join via URL Page

**`app/(dashboard)/join/[code]/page.tsx`** — Server Component with Client interactivity

This page handles the `/join/ABC123` URL flow:

**If user is NOT logged in:**
- Show project name and basic info (fetched by invite code)
- "Log in to join this project" button → `/login?redirect=/join/[code]`
- "Sign up" link → `/signup?redirect=/join/[code]`

**If user IS logged in:**
- Show project preview card: name, description, creator name, member count
- "Join This Project" button
- On click:
  1. Insert into `project_members` (user_id, project_id, role: 'member')
  2. Insert empty `availability` row for this user in this project
  3. Redirect to `/project/[id]`
  4. Toast: "Welcome to {project name}!"

**Edge cases:**
- Invalid code → "This invite code doesn't exist. Double-check with your team."
- Already a member → auto-redirect to `/project/[id]` with toast "You're already in this project"

### 3.8 Wire Up Dashboard Actions

Connect the "Create Project" and "Join Project" buttons on both the dashboard header and the empty state to open their respective modals.

After project creation or joining:
- Refresh the project list (router.refresh() or re-fetch)
- New project should appear in the dashboard
